Soldier of Fortune Platinum Edition README.TXT
=================================

SoF Platinum is based upon the 1.07f code. As of the creation date of this 
document, it is the latest code available to the public.



Minimum System Requirements

• 8MB 3-D Hardware Accelerator with full OpenGL support
• Pentium(R) 233 MHz processor (Pentium II recommended) OR Athlon
• 64 MB of RAM
• Microsoft(R) Windows(R) 95/98/ME/NT 4.0-SP5 or Windows(R) 2000 
  operating system
• 100% Windows 95/98/ME or NT-SP5-compatible computer system (including 
  compatible 32-bit drivers for CD-ROM, video card, sound card, and input 
  devices)
• 800 MB of uncompressed hard disk space, plus an additional 100 MB for the 
  Windows swap file
• Quad-speed CD-ROM drive (600k/sec sustained transfer rate)
• DirectX(R) 8
• 100% Windows 95/98/ME/NT/2000-compatible sound card and driver
• 100% Windows 95/98/ME/NT/2000-compatible mouse and driver
• Internet (TCP/IP) and LAN (TCP/IP and IPX) play supported
• Internet play requires a 100% Windows 95/98/ME/NT/2000-compatible 28.8 Kbps 
  (or faster) modem with Internet Service Provider


AUTOPLAY:
=========
If the Windows® Autoplay feature is enabled on your computer, the Soldier of 
Fortune Launch screen will automatically appear when you insert the Soldier 
of Fortune CD into your CD-ROM drive. Simply click on Install and follow the 
on-screen instructions to continue the installation.

If the Autoplay feature is disabled, you can begin the installation by doing 
the following:
a) Go to the Start Menu and select Run. 
b) Type D:\LAUNCH.EXE (assuming D is your CD-ROM drive letter) and press 
Enter. 

-or-

a) Double-click on your CD-ROM drive icon. 
b) Double-click on LAUNCH.EXE.

MONITORS (COLOR DEPTH AND RESOLUTION):
======================================
- Please make sure your monitor supports the game color depth and resolution 
you are trying to play in. To check what resolutions your monitor supports, 
do the following:
1. Open up My Computer 
2. Double-click on Control Panel 
3. Find the Display icon and open it. 
4. Choose the Settings tab.
5. Locate the resolution pointer in the Desktop Area box and drag it to the 
far right. 
6. Locate the Colors menu on the left and make sure it is set to at least 16-bit.

The resolution choice shown is the maximum resolution your monitor is capable
of displaying. If you do not want to change to this resolution now, select 
cancel. Your Desktop Area should be set to the game resolution you are trying
to play in or higher. 

NOTE: Please make sure your monitor type is properly specified to insure 
correct reporting of available video resolutions.

Previously Known Issues:
- TNT2: Users running Windows 2000 with TNT2 video cards may experience 
problems launching Soldier of Fortune unless the TNT2 Windows 2000 reference 
drivers are installed (you may not even be able to launch the game with the 
manufacturer drivers).

- Matrox G200 cards will perform slightly choppy on Windows 2000 once the 
Release drivers for windows 2000 are installed, but the card has issues with
changing video settings. After changing the video settings once, you will get
a blue screen if you attempt to change settings again. Clicking on the video 
tab will cause the computer to reboot itself.

- ATI Rage 128: on Windows 2000, you may not be able to run the game. The 
following error will come up:
"Error: Could not initialise OpenGL rendering enviornment!Make sure you have 
the latest drivers installed and make sure your desktop has more than 256 
colours." Please consult your hardware manufacturer for driver updates.

- If you are using a Diamond Stealth III S540 on a Windows 2000 system, you 
may experience some texture dropout if the Soldier of Fortune texture quality 
settings are changed below their defaults. When Texture Quality is set to 
very low, strips of purple and pink lines may appear through the walls. When 
quality is set to Low, some step textures may appear as red and white.

- VOODOO 3 cards will display a black screen if you task-switch (ALT+TAB) and
return to the game. You must quit out and use the Default Mode Soldier of 
Fortune shortcut to restart the game.


MODEMS:
=======
- Dial-up modems with auto-dial enabled will automatically attempt to 
establish an internet connection when you launch Soldier of Fortune.


SOUND PROBLEMS:
==============
- With Aureal Vortex 1 cards and Windows 2000, the settings for A3D and 
auto-detect do not function. Only default sound can be used. 

- Users with SB PCI512 sound cards will experience system slowdown if you 
change the driver settings to EAX. Default sound settings should be used for 
optimum performance with this board.


JOYSTICKS:
==========
- Additional information on joystick setup can be found in the "Manual

SCALABILITY OPTIONS:
====================
- The "Model Expressions" and "Skin Variety" settings on the Scalability Menu
cannot be altered while you are connected to a game (either Single or 
Multi-player). What this means is that you will have to quit the game and 
restart in order to change these settings. Or, if you have enabled the 
console, you can use the " ~ " key and type "disconnect" to quit out of the 
map. Press "ESC" to return to the Main Menu and you may alter the settings as
you please.


DEDICATED SERVERS:
=================
- You can launch a Dedicated Server from the shortcut on the Windows Start 
Menu. You can find more information on Dedicated Server commands in the 
"Manual Additions" portion of the online manual. 


DEBUG MODE:
==========
If you are having severe game-related problems while attempting to run 
S.o.F. Platinum, we have included a debug shortcut on the Start menu to help 
diagnose any issues within the game. Debug Mode should only be used under the
consultation of an Activision Customer Support representative.


FORCE FEEDBACK ISSUES: 
===================== 
- Logitech Force Feedback mouse users may experience a slight delay while 
playing Soldier of Fortune on a Windows 98 system. During tests, we have 
experienced Force Feedback driver crashes when exiting the game. Your computer
may freeze and need to be restarted if this scenario occurs.


SPECIAL FEATURES:
====================
- For Creative EAX users, we have included some brand new EAL (Environmental 
Audio Library) files on the S.O.F. Platinum CD. To install these files, 
simply proceed to the "EXTRAS" section from the S.O.F. Platinum Splash 
screen, and select the install option. To use these files, you should have a 
sound card that supports EAX2.0 (ideally you would want a SBLive card), and 
make sure you enable the EAX sound driver within the game. Future EAL files 
will be available from http://www.eax.creative.com/eagle/SOF. Also included 
in this version is a DLL from Creative Labs which emulates EAX2.0 on any 
card that supports EAX1.0. This would include SB PCI cards, Vortex2 cards, 
and older Sensura based cards. To install this feature, run the batch file 
in the SoF directory called "installeax.bat". Activision does not support the
use of these files. If you have a question regarding EAX, please consult your
hardware manufacturer, or go to: http://www.eax.creative.com. 

- To install GameSpy Arcade, proceed to the "EXTRAS" section from the S.O.F. 
Platinum Splash screen, and select the Arcade button. Installation is started
from this selection.

- It is recommended that you use Windows Media Player to view the SOF II trailer.
